*Hvor hører Simpl og testmiljøet Simpl-Labs hjemme i et veikart for norsk digital infrastruktur? Utkastet er et innspill til diskusjon. Målet, sporene og årstallene er forslag, ikke vedtatte planer.*

## Forslag til mål

Målet er ikke bestemt. Tre nivåer å velge mellom:

| Nivå | Formulering | Kommentar |
|---|---|---|
| Overordnet | Norge er verdens mest digitaliserte land i 2030 | Visjonen i [Fremtidens digitale Norge](https://www.regjeringen.no/no/dokumenter/fremtidens-digitale-norge/id3054645/?ch=2). Trygt, men sier lite om infrastrukturen |
| Midt (forslag) | Sammenhengende og tillitsbasert digital fellesinfrastruktur som fungerer sammen med Europa | Dekker samvirke, tillit og europeisk samarbeid uten å låse seg til én teknologi |
| Spisset | Tillitsbasert datadeling på tvers av sektorer og land, også som grunnlag for kunstig intelligens (KI) | Passer hvis data og KI skal stå i sentrum |

## Forslag til spor

| Spor | Utforske (2026–27) | Prøve ut (2027–28) | Ta i bruk (2029–30) |
|---|---|---|---|
| Identitet og tillit | EUs digitale identitetslommebok og digitale attester | | |
| Tilgang og bruksvilkår | Altinn Autorisasjon koblet til maskinlesbare vilkår for bruk av data | | |
| Data og beskrivelser | data.norge.no mot europeiske standarder for beskrivelser av datasett og tjenester | | |
| Datadeling og data spaces | **Simpl-Labs**, brukergruppen | **Erfaringer fra Simpl-Live**, piloter | |
| KI og sandkasser | Regulatorisk KI-sandkasse, Datatilsynets sandkasse | | |

Tomme ruter er åpne. De fylles når målet og initiativene er avklart.

---

## Hvor Simpl hører hjemme

- **Spor:** Datadeling og data spaces.
- **Ring:** Utforske. Simpl er i en tidlig fase, og brukergruppen for Simpl-Labs har oppstartsmøte i Brussel 9. desember 2026. Digdir er nylig tatt opp i brukergruppen.
- **På tvers av sporene:** Simpl-Labs er et testmiljø der løsninger fra flere spor kan prøves mot det europeiske oppsettet: identitet og attester, tilgang og bruksvilkår, beskrivelser av data, og samspillet med norske sandkasser for datadeling og KI. Det er vist med stiplede linjer i figuren.
- **Videre:** Erfaringene fra de første data spacene som tar Simpl i bruk (Simpl-Live), kan gi grunnlag for norske piloter i neste ring.

Begrunnelsen står i [Relevans av Simpl for norsk digital infrastruktur](/innsikt/eu-relatert/data-spaces/loesninger/simpl/relevans-for-norge/).

## Åpne spørsmål

- Hvilket nivå skal målet ligge på?
- Hvilke initiativer og løsninger skal med i hvert spor, og hvem eier dem?
- Er sporene riktige, eller mangler det noen, for eksempel sikkerhet eller kompetanse?
- Passer årstallene for ringene?
